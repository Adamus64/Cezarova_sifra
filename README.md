# Caesarova šifra (Python Console App)

Jednoduchá konzolová aplikace v Pythonu pro šifrování a dešifrování textu pomocí **Caesarovy šifry**. 

## 📌 Funkce
- **Šifrování textu:** Posune písmena v zadaném textu o určený počet pozic v abecedě dopředu.
- **Dešifrování textu:** Posune písmena o zadaný počet pozic zpět.
- **Podpora mezer a symbolů:** Speciální znaky, čísla a mezery zůstávají nezměněny.
- **Převod na malá písmena:** Vstupní text je automaticky převáděn na malá písmena anglické abecedy (`a-z`).
- **Interaktivní menu:** Jednoduché rozhraní přímo v terminálu.

## 🚀 Požadavky
- **Python 3.10+** (kód využívá konstrukci `match-case`)
